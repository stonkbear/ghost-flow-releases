# Ghost Flow releases

Public download mirror for Ghost Flow desktop (macOS, Windows, Linux) and Android builds.
Binaries only: the source code is not here.

- Downloads: see [Releases](https://github.com/stonkbear/ghost-flow-releases/releases)
- Website: https://ghost-flow.com

The desktop apps check this repository's releases for automatic updates. Every update is
verified against the app's built-in signing key before it is installed.
